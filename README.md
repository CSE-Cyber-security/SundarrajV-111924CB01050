# Fibonacci Series

A simple Python program to print the Fibonacci series for `n` terms.

## Problem Statement

Write a Python program to print the Fibonacci series for the given number of terms.

The Fibonacci series is a sequence in which each number is the sum of the two preceding numbers.

Example:

0, 1, 1, 2, 3, 5, 8, ...
